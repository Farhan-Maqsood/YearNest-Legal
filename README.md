## GitHub Pages deployment

1. Create the repository `YearNest-Legal`
2. Push the website files to `main`
3. Settings → Pages → Deploy from a branch → `main` / `(root)`
4. Wait for deployment

The site uses relative links so it works under the `/YearNest-Legal/` path.
